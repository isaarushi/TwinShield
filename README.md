TwinShield is a dual-brain AI system that builds two living digital twins simultaneously — a Behavioral Twin that models every customer as an evolving graph of financial personality, and a Regulatory Twin that maps every RBI circular as a live compliance state machine

---

## What It Does

TwinShield predicts where **fraud risk and regulatory change collide** — before either fully materializes.

Two AI twins run simultaneously:
- **Behavioral Twin** — every customer modeled as a living financial personality graph. Detects drift. Zero PII stored.
- **Regulatory Twin** — every RBI circular as a live compliance state machine. One circular auto-cascades to all affected systems.
- **Fusion Layer** — continuously cross-matches behavioral anomalies against compliance state changes. No existing tool does this.

---

## Five Agents

| Agent | Does |
|---|---|
| Circular Parser | Reads RBI PDFs, extracts obligations automatically |
| Impact Propagator | Maps blast radius of every new circular |
| Behavioral Watchdog | Scores every user's graph for fraud-preceding drift |
| Simulation Engine | Runs what-if scenarios, outputs risk probabilities |
| Remediation Planner | Auto-drafts policy fixes for human approval |
